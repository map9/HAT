公曆年(逆推儒略曆): -103(前104年)

農曆年:

丁丑(牛)(漢武帝太初元年)


秦朝及漢初(公元前221年 – 前104年)的曆法沿用顓頊曆的月序。顓頊曆是古六曆之一，據說戰國後期在秦國使用。顓頊曆以建亥(即今天的十月)為年首，但仍稱建亥為十月。月的數序是十月、十一月、十二月、正月、二月……九月，閏月置於年終，稱為後九月。秦朝的曆法與顓頊曆稍有不同。漢朝建立後基本上沿用秦曆，一百年間只作了少許修改，直到漢武帝太初元年(公元前104年)才頒行新曆法，以建寅(正月)為年首，並把閏月置於無中氣的月份，這使公元前104年的農曆年有十五個農曆月。秦朝為了避秦始皇名諱(正、政同音)，把正月改稱「端月」，到漢朝又改回正月。這裡沒有跟從歷史，在秦朝仍稱建寅為正月。
本網頁這時期的復原日曆是根據李忠林的文章「秦至汉初(前246至前104)历法研究—以出土历简为中心」，發表於《中国史研究》2012年第2期第17–69頁。具體計算方法在秦與漢初曆法網頁闡述。
